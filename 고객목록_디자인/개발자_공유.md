# 고객 · 일정 디자인 시안 — 개발자 공유

> 최종 갱신: 2026-11-17 · 시안은 **가상 데이터로 만든 HTML 한 파일**입니다. 실제 앱의 API · 권한 · 상태 흐름을 검증한 것이 아닙니다.
> 결정과 이유는 [`docs/의사결정_기록.md`](../docs/의사결정_기록.md)의 **D-19(고객 목록 · 상세) · D-20(일정)** 에 있습니다. 이 문서는 개발에 필요한 동작만 줄여 적은 것입니다.

## 1. 열어 보는 법

- `고객목록_디자인/index.html`을 브라우저로 엽니다(서버 불필요). 상단 탭 「**인터뷰 반영안 v4**」가 최신입니다. 「기존 시안 v3」 · 「상단 기능 기획서」는 이전 기록입니다.
- 폭 390px 휴대폰 틀 안에서 눌러 볼 수 있습니다. 왼쪽 「현행」은 현재 앱을 그린 와이어프레임입니다.
- 오른쪽 **「보기 옵션」** 패널:
  - 고객 메뉴: 목록 카드 시안(K-0~K-4) 바꾸기, 인터뷰 의견 표시 켜기/끄기
  - **일정 메뉴: 일정 시안 A / B 바꾸기**
- 왼쪽 아래 「요소 선택」: 화면 요소를 눌러 위치를 글로 복사합니다(대화에 붙여 넣는 용도).
- 비교용 페이지: `카드제안.html`(카드 · 메모 · 긴 메모 안), `일정상단_제안.html`(일정 상단 배치).

## 2. 고객 목록

| 영역 | 동작 |
|---|---|
| 카드 (K-2) | 이름 · 현장(매체) · 관심도 · 상태. 메모가 **있을 때만** 회색 메모 박스. 맨 아래 등록 시각 · 담당자, **전화번호 알약을 누르면 전화**. 카드 본체를 누르면 고객 상세 |
| 검색 | 머리글 「검색」 → 전용 화면. 이름 · 전화 · 현장 · 메모 · 통화 내용. 고른 캠페인 · 상태 · 필터와 무관하게 전체에서 찾음. 범위 칩 · 최근 검색 |
| 필터 · 정렬 | 담당자 · 관심도 · 플랫폼 · 등록일 칩. 정렬은 목록 위 오른쪽 버튼(7개 중 선택) |
| 캠페인 | 제목 옆 전환 버튼, 하나만 선택 |
| 등록 | 떠 있는 ＋ 버튼(스크롤해도 유지) → 고객 등록 시트. 「추가 정보」는 펼친 상태가 기본. 중복 번호는 기존 고객을 알림 |

## 3. 고객 상세

- **구역 탭:** 기본 정보 · 메모 · 통화 이력 · 미팅 예약 · 타임라인(눌러 해당 구역으로 이동, 스크롤하면 탭이 따라감).
- **기본 정보 수정 시트:** 맨 아래에 「고객 삭제」. 가운데 정렬의 확인 단계(「휴지통으로 옮겨지며 복원할 수 있습니다」).
- **메모:** 「추가」 버튼 → 작성 시트(양식: 자유 메모 · ◆ 상담내용 · ■ 입금보고. 양식이 달라도 시트 높이 고정). 메모 박스를 누르면 수정 · 삭제 시트. 긴 메모는 접고 「더 보기」, 상단 종류 칩으로 거름.
- **미팅 예약(방문):** 날짜 칩(오늘부터 14일 + 「다른 날」 달력) · 시작 / 종료 **셀렉트** · 담당자 · 참고 메모. 수정 시 「삭제」 버튼 포함.
- **통화 이력:** 요약과 전체 대화 보기 펼침. **내페이지 활동:** 마지막 활동 요약 + 목록(체류 시간은 「체류」). 내페이지 공유 시트.

## 4. 일정 메뉴 (하단 탭 「일정」)

### 공통 상단

```
[2026. 11. ˅] [‹] [›] [오늘]                [🔍] [≡]
[캠페인 ˅] [담당자 ˅]                         휴가 등록
```

- 날짜 글자 → 월 선택 시트(2026년 12개월). 이전 · 다음 달 버튼(1월 · 12월에서 비활성).
- **필터는 달력 위**, 휴가 등록은 칩이 아닌 글자 버튼(필터와 혼동 방지).
- 검색 아이콘 → 고객 검색 화면을 그대로 연다(일정 기준 검색은 미정).
- 일정 등록은 하단 파란 ＋ 버튼.

### 시안 A — 달력은 작게, 아래에 일정 카드

- 선택한 날 줄: 「11월 1일 일요일」 + 건수(필터가 걸리면 조건을 작게 표시).
- **일정 카드(고객 카드와 같은 모양):** 시간 · 이름 · 현장명 · 관심도 · 메모(항상 표시, 없으면 「최근 메모가 없습니다」) · 담당자.
  - 카드를 누르면 **그 고객의 상세**로 이동.
  - 오른쪽 위 「수정」 → 고객 상세와 같은 **방문 일정 수정 시트**(삭제 포함).

### 시안 B — 달력 칸 안에 표시

- 칸마다 점 + 고객명(최대 2건, 넘으면 「+N건」). 선택한 날은 옅은 회색 칸, 오늘은 파란 원. 아래에 선택한 날 요약.
- 색 띠 · 막대 모양은 쓰지 않는다(사용자 지시).

### 시트

- **일정(방문 예약) 등록:** 고객 · 날짜 · 시작 / 종료(셀렉트) · 담당자 · 예약 참고 메모.
- **휴가/부재 등록:** 매니저(선택) · 시작일 · 종료일 · 사유(휴가 · 병가 · 외근 · 퇴사) · 메모 · 「등록 즉시 해당 매니저의 배정 가중치가 자동 0 처리됩니다. 종료일이 지나면 자동 복원됩니다.」
- 현행 앱의 삭제 확인 문구: 「○○ 고객의 방문 일정을 삭제할까요? 삭제한 일정은 되돌릴 수 없습니다.」

## 4-2. 홈 · 멤버 · 메뉴 (하단 탭)

- 하단 탭 다섯 개(홈 · 고객 · 일정 · 멤버 · 메뉴)가 모두 눌립니다. 머리글의 ≡ 아이콘은 두지 않았습니다(메뉴로 들어가는 길을 하단 탭 하나로 통일, D-21).
- **홈:** 인사말 → 캠페인 · 플랫폼 · 기간 필터 → **오늘의 업무** → **오늘 일정** → 주요 지표(타일 4개) → 일별 리드 추이 → 광고 현황 → 담당자별 실적 → 고객 상태 현황(누적 막대 + 범례) → 최근 활동. 카드의 이름을 누르면 고객 상세, 「전체 보기」 · 「캘린더」는 해당 화면으로 갑니다. 플랫폼 · 기간 칩은 광고 현황과 같은 선택 시트를 쓰고 값도 함께 따라갑니다.
- **멤버:** 「멤버 전체 / 캠페인별 팀」 세그먼트. 멤버 카드(이름 · 역할 칩 · 이메일 · 담당 현장), 진행 중인 초대.
- **메뉴:** 전체 화면 목록(내 프로필 → 워크스페이스 → 관리 → 설정 → 로그아웃). 할일은 건수, 메시지는 안 읽음 점.
- **하위 화면:** 광고 현황(기간 + 지표 6개) · 할일(방문 / 재통화 / 리마인더) · 최근 활동(상태 칩) · 메시지(모두 / 안 읽음 / 즐겨찾기) · 자료함(빈 상태) · 휴지통(복원 / 영구 삭제 동작) · 내 페이지 관리(빈 상태) · 설정(토글 동작) · 프로필 편집 · 사용 가이드.
- **모든 버튼이 동작합니다.** 목록 · 필터 · 시트 · 확인 창이 눌러서 이어지고, 입력한 값(초대, 메시지, 업로드한 자료, 만든 페이지, 상태 이름 등)은 화면을 새로 고치기 전까지 유지됩니다. 서버와 연결된 것은 아닙니다.
- **현행에 없는 부분은 스토리보드(화면설계서)를 참고해 유추한 것입니다(D-21 8번).** 유추한 화면: 메시지 대화방 · 새 대화 · 고객 카드 공유, 멤버 초대 · 캠페인 배정 · 비활성화, 자료함 목록 · 업로드, 내 페이지 만들기 · 공개, 상태 지정 · 호칭 · 알림 시간 설정, 프로필 본인인증 · 비밀번호 · 탈퇴, 알림 목록(홈 종 아이콘으로 진입 — 현행은 들어가는 길이 없음), 사용 가이드 단계 보기. 개발 기준은 스토리보드의 해당 화면(MS-01 · MB-01 · FL-01 · MP-01 · ST-01~07 · NT-01 · GD-01)을 따릅니다.
- 현행 화면에 있는 항목은 모두 남기고 모양만 v4 규칙으로 바꿨습니다(D-21). 이메일 · 이름은 가상 값입니다.

## 5. 공통 디자인 규칙

- 꺾쇠(˅ ˄ ‹ ›)와 뒤로가기(←)는 **한 계열의 선 아이콘**(두께 2.3, 둥근 끝)으로 통일.
- 버튼은 글자 알약(「추가」 · 「수정」), 필터는 테두리 칩, 주 행동은 파란 채움.
- 등록 · 수정은 모두 **바텀시트**, 삭제는 가운데 정렬의 확인 단계를 거친다.
- 시안 안의 담당자 이름은 가상(「담당자 1~3」, 목록은 박성훈 · 김태윤 등). **실제 값이 아니다.**

## 6. 열린 질문 · 확인하지 못한 것 (구현 전에 정해야 함)

1. 일정 시안 **A / B 중 선택** (아직 미정).
2. 일정 **검색**: 고객 기준 그대로 둘지, 일정(날짜 · 시간) 기준이 필요한지.
3. 일정 수정 · 삭제가 **달력에 반영되는 방식**(시안은 저장 안내만 뜨고 데이터는 안 바뀜).
4. 월 선택에서 **연도 이동**(시안은 2026년만).
5. 일정 등록 시트의 **담당자 이름**이 고객 목록의 담당자 이름과 일치하지 않음.
6. **상태 · 권한 화면**은 만들지 않았다(미배정 담당자, 메모 · 방문 삭제 확인, 저장 실패, 역할별 화면, 통화 종류 · 짧은 통화, 목록 끝 안내 등).
7. 스토리보드(`영업비서 화면설계서 스토리보드`) 기준의 기능 점검은 아직 하지 않았다.
8. 홈 · 멤버 · 메뉴: 서비스 문구 사용 여부, 자료 · 내 페이지가 있을 때의 화면(현행 캡처 없음).
9. **검수 상태:** 문법 점검과 가짜 DOM 실행으로 대부분을 확인했고, 일부 화면만 브라우저로 직접 확인했다. 좁은 화면(390px 이하), 접근성, 실제 기기 터치는 확인하지 않았다. `검수_v4.md`에 다른 도구로 한 검수 결과(미수정 제안 포함)가 있다.
