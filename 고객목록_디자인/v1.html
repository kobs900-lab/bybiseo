개선 기획 SCR-01(고객 목록)을 실제 화면 수준으로 그린 시안입니다. 왼쪽 화면은 직접 눌러 볼 수 있습니다. 고객 데이터는 모두 가상이고, 상태별 고객 수는 실제 규모를 보여 주기 위한 표시입니다. 목록에는 예시 고객 14명만 나옵니다.

현행에서 달라진 점

영역현행시안
상태 고르기「전체 13개 ▾」 드롭다운과 가로로 미는 칩 13개가 같이 있음기본 상태 6개는 한 줄 타일로 항상 보이고, 커스텀 상태는 버튼 하나로 접음
적용 조건필터를 걸어도 목록에서 보이지 않음건 조건이 칩으로 보이고 ✕로 바로 해제. 버튼에 개수 표시
정렬필터 시트 안에만 있음위치는 그대로, 기본값이 아닐 때만 목록 위에 칩으로 표시
카드 아래 정보모든 고객이 「📝1 · 예약 없음 · 최근통화 없음」다음 일정 · 최근 통화 · 기록 수를 실제 값으로. 없는 값은 생략
AI 키워드사용자가 붙인 태그처럼 보임✦ 표시를 붙이고 2개까지만
전화 버튼상태 배지 바로 옆이라 잘못 누르기 쉬움배지와 떨어진 카드 오른쪽 아래에, 고객마다 주 행동 1개
시트아래쪽이 하단 탭에 가려짐시트가 하단 탭을 덮고, 결과 수를 버튼에 미리 표시

현행 화면

  • 고객 정보를 가린 캡처입니다.
  • 상태 13개(전체 포함)를 보려면 3~4번 밀어야 합니다.
  • 카드 아래 줄이 모든 고객에게 같은 값으로 나옵니다.
  • 근거: 문제점 목록 L1~L6, S1, F1, F6.

눌러 볼 수 있는 것

  • 기본 상태 타일 · 「전체」 · 「커스텀 상태 6」 펼치기와 선택
  • 「필터·정렬」 시트: 정렬 5 · 담당자 · 관심도 3 · 플랫폼 7 · 캠페인 12 · 등록일 5
  • 조건 칩 ✕ 해제, 결과 0명일 때 빈 화면
  • 검색 아이콘: 이름 · 메모 · AI 요약 · 키워드에서 찾고 일치한 글자를 표시
  • 카드 · 주 행동 버튼 · ＋ · 하단 탭은 안내 문구만 나옵니다(이번 범위 밖).

색 · 글자

색은 상태 구분에만 씁니다. 기본 상태는 옅은 바탕 배지, 커스텀 상태는 흰 바탕에 테두리 배지로 나눴습니다. 커스텀 상태의 색은 관리자가 정한 색을 점으로만 보여 줍니다.

글자는 Pretendard. 이름 17 · 본문 14 · 보조 13 · 배지 12. 누르는 영역은 모두 40px 이상입니다.

지킨 결정 · 남은 확인

  • D-07 상태는 기본 6개 + 커스텀 최대 6개. 줄이거나 합치지 않았습니다.
  • D-08 상태 영역은 처음에 접어 둡니다.
  • D-09 정렬은 필터 시트 안에, 목록에는 기본값이 아닐 때만 보입니다.
  • 하단 탭과 ＋ 버튼은 이번 범위가 아니라 현행 모양을 유지했습니다. 다만 ＋ 버튼이 카드의 행동 버튼을 가리지 않게, 아래로 내릴 때는 숨기고 위로 올리면 다시 보입니다.
  • 확인할 것: 고객마다 주 행동을 상태에 따라 바꾸는 규칙(미지정 · 부재중 = 전화, 방문 예약 = 문자, 계약 = 기록)이 현장 업무와 맞는지.
