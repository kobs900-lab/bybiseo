- 두 종류의 계약:
  광고주의 광고 계약·결제 회차와 상담 고객의 가계약·정계약은 다릅니다.
- 미배정:

  통화 기록, 음성 녹음, AI 분석 결과는 서로 다른 데이터·처리 경로입니다.

- 내 페이지 저장은 즉시 공개라는 설명. 브라우저 편집 복원과 발행 전 임시저장을 혼동하지 않음.
- 현장 묶음에서 제외하는 것과 캠페인 연결을 끊는 것은 영향이 다름.
- 기간별 리드와 누적 비용·CPL 등 집계 범위가 혼재할 수 있음.

4) 자료가 상충하는 기능: AI 분석의 자동/수동 시작 조건, 사이트 연결 후 과거 미배정 자동 처리와 별도 배정 버튼의 차이, 휴가 표시와 배정 제외의 관계.
5) 역할별 조회·수정·금액 공개 범위와 정상/빈 결과/권한 없음/통신 실패 구분.
6) 응대·미응대·활동 광고주·유효 DB·CPL 등 지표의 분모, 기간, 채널, 확정 시점.
