# 사용자에게 물어볼 질문 — 영업비서 「고객」 탭

설계를 정하기 전에 실제 사용자(영업 담당자, 팀장 · 관리자)에게 직접 물어볼 질문입니다.
**★ 표시**는 지금 열려 있는 설계 결정을 바로 좌우하는 질문입니다. 시간이 없으면 ★만 물어도 됩니다.
「답에 따라」 칸은 답이 어느 쪽이냐에 따라 화면이 어떻게 달라지는지 적은 것입니다. 결정 번호(D-00)는 [의사결정 기록](./의사결정_기록.md)을 가리킵니다.

묻는 요령 세 가지.

- "자주 쓰세요?"보다 "어제는 몇 번 쓰셨어요?", "마지막으로 쓴 게 언제예요?"처럼 실제 행동을 묻는다.
- 가능하면 말로 듣지 말고 폰 화면을 보여 달라고 한다. 상태 목록과 메모 한두 개만 봐도 답이 나온다.
- 담당자와 관리자는 쓰는 화면이 다르므로 누구의 답인지 적어 둔다.

## A. 하루 흐름과 쓰는 상황

| # | 질문 | 답에 따라 |
|---|---|---|
| A1 ★ | 앱을 주로 언제, 어디서 여나요? (모델하우스, 이동 중, 사무실, 퇴근 후) | 한 손 조작과 큰 버튼이 얼마나 중요한지. 이동 중이 많으면 입력을 고르기 위주로 |
| A2 ★ | 앱과 PC 웹을 각각 어떤 일에 쓰나요? | 앱에서 덜어 낼 기능과 꼭 있어야 할 기능 구분 |
| A3 | 아침에 앱을 열면 가장 먼저 무엇을 하나요? | 고객 탭 첫 화면에 무엇을 먼저 보여 줄지 |
| A4 | 하루에 전화를 몇 통쯤 걸고, 그중 앱에서 거는 건 얼마나 되나요? | 전화 버튼의 위치와 크기, 통화 결과 화면의 비중 |

| B7 | 상태는 언제 바꾸나요? 통화 직후인가요, 하루 끝에 몰아서인가요? | 통화 결과 화면에서 상태를 함께 바꾸는 제안의 효용 (SCR-06) |
| B8 | 상태 옆 숫자(고객 수)를 보나요? 보고 무엇을 판단하나요? | 타일에 숫자를 크게 둘 가치가 있는지 |

## 말로 묻지 말고 화면으로 확인할 것

- 상태 설정 화면: 실제로 몇 개를 쓰는지, 이름과 순서가 무엇인지.
- 최근 메모 서너 개: 양식을 지키는지, 무엇을 주로 적는지.
- 필터를 건 상태로 화면이 남아 있는지.
- 상세 화면을 스크롤하는 모습: 어디서 멈추고 무엇을 찾는지.
